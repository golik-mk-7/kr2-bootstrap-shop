# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание проекта
Проект представляет собой версию сайта питомника «Marydivita», разработанную с использованием CSS-фреймворка Bootstrap 5. 

## Используемый фреймворк
Bootstrap 5.3.3

## Способ подключения
Bootstrap подключён через CDN (jsDelivr). Файл `css/custom.css` подключён локально для настройки фирменных цветов.

## Структура проекта
- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — страница товара с аккордеоном;
- `order.html` — форма заявки;
- `css/custom.css` — собственные стили;
- `images/` — папка с изображениями.

## Реализованные Bootstrap-компоненты
- **Сетка**: `container`, `row`, `col-12`, `col-md-6`, `col-lg-4`, `g-4`;
- **Навигация**: `navbar`, `navbar-expand-lg`, `navbar-toggler` (мобильное меню);
- **Карточки**: `card`, `card-body`, `card-title`;
- **Кнопки**: `btn`, `btn-primary`, `btn-outline-primary`;
- **Значки**: `badge` (Новинка, Хит, Скидка);
- **Сообщения**: `alert` (на странице каталога);
- **Формы**: `form-control`, `form-select`, `input-group`, `form-check`;
- **Модальное окно**: `modal` (вызывается кнопкой «Заказать» на главной);
- **Дополнительный компонент**: `accordion` (на странице товара).
